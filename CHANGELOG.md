# Changelog

## Unreleased

- Admin-only WordPress XML/JSON draft imports, local media matching, original dates, duplicate detection and per-post review reports.
- Redirect manager with validation and JSON/Nginx/Apache/Netlify exports. Unpublished blog destinations are withheld.

## 0.1.0-alpha.1

Initial public source release for local evaluation:

- Invite-only admin/editor access with Better Auth and SQLite.
- Tiptap editor, immutable Markdown revisions, previews and optimistic saves.
- Multiple categories, category archives, post filters and bulk actions.
- Featured/inline uploads with configurable dimensions, ratio, format and quality.
- Astro Content Collections example, isolated builds and atomic local release activation.
- Responsive dashboard, app confirmations, test suite and backup/source export tools.

Production deployment, scheduled publishing, email delivery, automatic rollback and retention management are not included.
